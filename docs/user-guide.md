# AI工作 · Android 2.3.4

适合不熟悉提示词的工作者使用的中文 AI 办公助手。深色界面、大字号、大按钮；安装包不包含任何真实 API Key，无需自建服务器。

本次视觉优化：主题改为深海蓝 / 冰蓝冷色，页面切换、消息入场、面板展开/收起及按钮反馈采用短时缓动。原布局位置、文字、业务流程、API 设置和版本号保持不变；系统启用“减少动态效果”时会停止非必要过渡。此次仅修改软件界面配色，不改变 Excel / PPT / PDF 的导出模板。

## 安装和开始

1. 将同目录的 `AI-work-v2.3.4.apk` 传到安卓手机，打开安装。系统询问时允许本次安装来源。
2. 打开「AI工作」→「设置」，粘贴您自己的 DeepSeek API Key。
3. 默认 API 地址为 `https://api.deepseek.com`，模型为 `deepseek-flash`。点击「保存设置」，再点「检测已保存的连接」。
4. 回到工作台，选择工作流，直接用日常语言描述要做的工作。需要参考资料时点击「添加资料」。
5. 在工作台聊天输入框点击「发送」。App 会先让 AI 优化您的需求，再将优化后的需求和附件交给 AI 执行；进度和成果显示在同一段对话中。
6. 在成果底部点击导出，在手机系统窗口选择保存位置。可以保存到「下载」或文件管理器提供的位置，再通过微信、邮件或办公软件分享。

如希望自己把关优化结果，在设置中开启「执行前先让我确认」。优化后可修改文字，再点击制作；关闭该开关时自动连续完成两步。聊天中可以直接继续发送修改要求，App 会携带上一版成果和本次会话已读附件作为参考。「我的成果」里的「继续修改」入口也仍然保留。

## 聊天工作台

- 工作台已改为普通聊天布局：上方对话记录，下方固定输入栏；键盘弹出时输入栏随之上移。
- 输入栏内可以添加资料、选择工作流或填入示例。其他工作流页、成果页、设置页保持原样。
- 每条 AI 成果下方均可导出对应文件；导出较早的回复不会误导出最新回复。
- 执行时始终携带原始需求，优化内容不能将原任务变成“继续写提示词、不执行任务”。查询需求与制表、PPT、PDF 可以串联使用联网检索；检索失败会明确标注，不会冒充已核实信息。
- 表格、PPT 或 JSON 结构缺失时，App 最多自动补全一次；依然失败会保留可读取的已返回文字。没有真实资料时可生成带字段的空表，但不会把虚构数据当查询结果。
- 连续聊天会携带近期最多 8 轮用户消息、已确认需求和成果作为参考；超长内容按长度预算节选，并标注省略位置。需要逐字引用长材料时，请重新添加原文附件。
- 「新对话」清空当前聊天显示和临时附件，不删除「我的成果」。
- 当前聊天通过本机成果记录恢复，最多 30 份；重新打开 App 后原始附件仍需重新添加，附件不永久保存在历史中。
- 应用名和版本仍为「AI工作 2.3.4」。本次为同签名覆盖更新，保留已有设置。

## 内置 8 个工作流 / Skills

| 工作流 | 主要用途 | 文件输出 |
|---|---|---|
| 信息查询 | 查资料、对比方案、整理依据和行动清单 | TXT / PDF |
| 表格制作 | 费用、排班、统计、空白模板 | XLSX / PDF / TXT |
| PPT 汇报 | 工作汇报、培训、项目介绍，附讲稿 | PPTX / PDF / TXT |
| PDF 文档 | 方案、报告、正式说明 | PDF / TXT |
| 会议纪要 | 议题、结论、负责人、截止日期、待办 | PDF / TXT，可含 XLSX |
| 工作总结 | 周报、月报、成果与下期计划 | PDF / TXT |
| 通知公文 | 通知、申请、工作邮件 | PDF / TXT |
| 资料解读 | 解释文件、截图、视频抽帧中的重点 | TXT / PDF |

这些 Skill 不只是名称：每项包含独立的需求优化上下文、事实约束、输出规范及示例；查询工作流可调用联网检索，表格和 PPT 工作流会校验结构并生成对应的可编辑 Office 文件。

## 附件支持范围

- 文字直接输入；最多 12,000 字。大量材料建议作为文件导入。
- TXT / MD / CSV / JSON / TSV / LOG：读取文本，兼容常见 UTF-8、UTF-16 与 GB18030 编码。
- DOCX / XLSX / PPTX：提取文字、数字、公式已有缓存。不会运行宏，不保留原文件版式及内嵌图片。不读取旧版 DOC / XLS / PPT，可先转为新格式或 PDF。
- 图片：压缩后交给视觉模型读取。默认模型支持视觉；自定义模型需要具有图片能力。
- PDF：将前 8 页转换为图像供 AI 阅读。超过部分明确提示未读取；加密、损坏或系统不支持的 PDF 会提示读取失败。
- 视频：在全片均匀抽取最多 6 个静态画面，并附抽帧时间说明。**不转写声音，不等同于完整视频理解**；需要会议语音内容时，请另行上传文字记录。Android 8.0 的原生解码接口有限，本版本在该系统上只接受 1080p 像素量以内的视频；超过时提示先压缩或提供截图。
- 每个文件最多 25 MB，每个任务最多 6 个用户附件。文字材料提取最多 60,000 字；超限会在附件说明中标注。Office 还设有解压体积限制，防止超大文件耗尽内存。

## 文件与数据

- Excel 是真实 `.xlsx`，数字保持数值类型，含表头、冻结首行及筛选。模型输出的类似公式字符串按普通文字写入，不执行公式。
- PPT 是真实 `.pptx`，16:9 深色版式，文字可编辑，包含每页讲稿。
- PDF 在手机端生成，白底中文正文、多页排版；表格内容以逐项文字列表呈现，完整表格可以另导出 Excel。
- 文件通过 Android 系统保存窗口写入您选定的位置。取消保存不会影响本机成果记录。
- 「我的成果」最多保留 30 条本机记录，支持重新打开、继续修改和再次导出。重要内容请及时保存为文件；卸载 App 会移除本机数据。
- 历史不保存原附件。重启后可恢复未完成任务的原始需求，但需要重新添加附件；App 不会自动重放可能计费的请求。

## API 与隐私

- Key 通过 Android Keystore 的 AES-GCM 加密后保存在手机，安装包及源码不包含真实 Key。
- 任务文字、附件提取文本及图像会发送给您设置的 HTTPS API 服务，API 消耗由该服务账户承担。
- 一次完整任务通常包含 2 次模型请求；如果输出结构缺失，最多增加 1 次格式补全请求。「继续修改」也是新一轮请求。开启联网查询时还会调用搜索接口，可能额外计费。
- 自定义 API 地址必须为 HTTPS。更换服务地址时需重新输入对应服务的 Key，避免将旧 Key 自动发送至新服务。
- 如果兼容服务不支持 DeepSeek 搜索接口，在设置关闭联网检索即可进行知识整理。没有联网来源的结果会提示未联网核验。
- 优化失败不会继续执行；生成失败可只重试生成步骤，不重复优化。查询生成阶段重试可能重新检索。

## 运行要求

- Android 8.0（API 26）或以上；已启用、正常工作的 Android System WebView（Chrome 61+）。建议保持系统 WebView 更新。
- 无需注册 App 账号，无需电脑持续开机。AI 任务及联网查询需要网络连接。
- 当前 APK 为本地证书签名的侧载构建，不是应用商店发布包。未来覆盖更新必须沿用同一签名证书。
